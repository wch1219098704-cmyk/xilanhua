导入单词

一行一个词，从微信/文档直接粘进来就行。自动识别这些格式：
01 avoid v. 避免；回避　avoid,避免
1 avoid 避免　avoid　　避免
行首的数字会被当作序号原样保留，没有数字才自动排。

怎么用

  • 点英文单词 → 朗读一遍
  • 顶部「汉语」按钮（或底部开关）→ 一键隐藏 / 一键显示全部汉语
  • 点卡片空白处 → 只翻这一张，方便当场核对
  • 点右上角小方块 → 标记「不会」，再点一下取消
  • 标记自动保存在本机，关掉再开还在

此页词库是只读的：不能添加、不能修改。标记只保存在你自己的设备上，不影响别人。

以后加词

  • 右上角 ＋ → 粘贴 → 确认导入
  • 序号以你文本为准：行首的 01 / 1 / 1、 原样保留，页面不另编号
  • 没有序号的行，才从本单元最大值往后自动排
  • 可填「单元名称」，不同批次分开筛；不填按「第N批」自动命名
  • 同一个英文重复导入 = 更新释义，不重复，也不会改你原来的序号
  • 本页「说明」里的 备份全部单词 → 导出一份 txt，换设备时粘回去即可

发音源：默认用有道词典的真人录音（美音），点底部「美音/英音」可切换。 没网络时会自动退回系统合成音。慢速开关对真人音是放慢播放，不改变音调。

记单词的四种方法

按好用程度排序。看到能拆的就拆（3 秒够了），拆不了直接硬记，别硬编故事。

① 合成词拆 —— 最直观

under + graduate还没毕业 → 本科生
under + take把担子拿到身下 → 承担
under + ground地下的 → 地铁
under + line在下面划线 → 强调
under + neath在下面 → 在……下面
back + ground后面的场地 → 背景
head + line头一行 → 标题
dead + line死线 → 截止日期
broad + cast广泛撒播 → 广播
broad + en使宽 → 变宽，扩展
fresh + man新来的人 → 大一新生
scholar + ship学者身份 → 奖学金
neighbour + hood邻居们那片 → 街区

`under-` 一家开了 5 个词的头，记住一个等于拿下五个。

② 前缀 —— 一个前缀管几十个词

en- 使enable 使能够
un- 不、相反uncover 揭开
dis- 去掉discover 发现；disabled 残疾的
mis- 错misunderstand 误解
im- 向内immigrate 移入
in- 里面inhabit 居住于
fore- 前foresee 预见
ex- 出except 除外
a- 使、去avoid 避开（让路空出来）

③ 同族串联 —— 一次记一串

able 能够
 ├ ability      能力
 ├ enable       使能够
 └ disabled     残疾的

act 行动
 ├ action       行为
 ├ active       积极的
 └ activity     活动

cover 盖
 ├ discover     去掉盖子 → 发现
 └ uncover      揭开

profess 声称
 ├ profession   职业
 ├ professional 职业的
 └ professor    教授

migrate 迁移
 ├ immigrate    移入
 └ migration    迁移

comprehend 理解
 ├ comprehension 理解力
 └ comprehensive 全面的

④ 两大词根 —— 一次管十几个

combinecom(一起)+bine(两个) → 结合
compoundcom+pound(放) → 放一起 → 混合物
complexcom+plex(编织) → 编在一起 → 复杂的
communitycom+mun(服务) → 互相服务 → 社区
communicatecom+mun → 一起分享 → 交流
comprehensivecom+prehens(抓) → 全抓住 → 全面的
comprehensioncom+prehens(抓) → 抓住意思 → 理解力
captaincapt(头)+ain(人) → 头头 → 船长
capitalcapit(头) → 首都／资本／大写字母
capturecapt(抓) → 抓住 → 捕获
capablecap(拿得住)+able → 有能力的
capacitycap+acity → 能装多少 → 容量

⑤ 谐音 —— 只对拆不了的用

avoid「额，躲」→ 避开
campuscamp(营地)+us(我们) → 我们的营地 → 校园

过词的时候：能拆的心里拆一下，同族的想一下“还有谁是这家”，拆不了的直接硬记。 方法是省时间的，不是加任务的。
